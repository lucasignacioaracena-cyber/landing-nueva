# Matrona Guía — versión para navegador

Esta rama contiene la web compilada para GitHub Pages.

Activación de una sola vez: [Settings → Pages](https://github.com/lucasignacioaracena-cyber/landing-nueva/settings/pages) → Deploy from a branch → gh-pages → /(root) → Save.

GitHub mostrará el enlace público al terminar el despliegue.

Los formularios preparan mensajes por WhatsApp. No se requiere un servidor para esta versión.

El código y las instrucciones para actualizar están en [web-interactiva](https://github.com/lucasignacioaracena-cyber/landing-nueva/tree/web-interactiva).
